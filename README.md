# Дипломный проект: Информационная платформа для публикации учебного видеоконтента студентов

# О проекте
Разработан веб-сайт, позволяющий студентам публиковать свои учебные видеоматериалы (лабораторные работы, проекты, демонстрацию навыков), формировать видео-портфолио, а преподавателям — просматривать, комментировать и оценивать работы.

# Функциональные возможности
- Регистрация и авторизация пользователей
- Разграничение ролей: студент, преподаватель, администратор
- Загрузка видео (форматы MP4, WebM, до 1 ГБ)
- Просмотр ленты видео с поиском и фильтрацией (новые/популярные)
- Система комментариев и лайков (без перезагрузки страницы)
- Личный кабинет (управление своими видео)
- Админ-панель (управление пользователями и контентом)

# Технологии
- **Backend:** PHP
- **База данных:** MySQL
- **Frontend:** HTML5, CSS3,
- **Интерактивность:** PHP
- **Сервер:** XAMPP

# Структура проекта

video_portfolio/
├── config/
│   └── database.php          # Подключение к БД и сессии
├── api/                      # API
│   ├── get_videos.php        # Получение списка видео
│   ├── toggle_like.php       # Постановка/снятие лайка
│   └── add_comment.php       # Добавление комментария

├── index.php                 # Главная страница (лента видео)
├── register.php              # Регистрация
├── login.php                 # Авторизация
├── logout.php                # Выход
├── upload.php                # Загрузка видео
├── watch.php                 # Просмотр видео
├── profile.php               # Личный кабинет
└── admin.php                 # Управление пользователями (админка)
            
# Установка и запуск

1. Установите MAMP (или OpenServer/XAMPP)
2. Скопируйте папку `video_portfolio` в `htdocs`
3. Импортируйте базу данных из файла 
4. Настройте подключение к БД в `config/database.php` (порт 3306 для MySQL в XAMPP)
5. Откройте в браузере: `http://localhost/video_portfolio/`
